# Giai đoạn 1: Test Design (Tuần 3–4 · 3 tuần)

> **Bám syllabus:** Tuần 3–4  
> **Trọng tâm:** Kỹ năng cốt lõi nhất của tester, thường được hỏi nhiều khi phỏng vấn.

## Checklist kiến thức & kỹ năng

### Black-box testing
- [ ] Equivalence Partitioning (EP)
- [ ] Boundary Value Analysis (BVA)
- [ ] Decision Table
- [ ] State Transition
- [ ] Use Case Testing
- [ ] Pairwise

### White-box testing *(lợi thế từ góc nhìn dev)*
- [ ] Statement coverage
- [ ] Branch coverage
- [ ] Condition coverage
- [ ] Path coverage
- [ ] Cyclomatic Complexity

### Experience-based testing
- [ ] Error guessing
- [ ] Exploratory testing

## Thực hành

- [ ] Lấy từng form (đăng ký, checkout, voucher) trong project của bạn, thiết kế test bằng cả 4 kỹ thuật rồi so sánh số lượng test case và bug tìm được.

## Deliverable

- [ ] Một bộ **test design document** có truy vết yêu cầu (**traceability matrix**).
