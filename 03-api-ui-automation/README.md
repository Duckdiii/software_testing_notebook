# Giai đoạn 3: API + UI Automation (Tuần 7 & 14 · 5 tuần)

> **Bám syllabus:** Tuần 7, 14  
> **Nguyên tắc cần nhớ:** Giữ UI test ở mức tối thiểu (đỉnh pyramid). Cả *Agile Testing* và *Full Stack Testing* đều nhấn mạnh điều này.

## 3a. API Testing (2 tuần)

- [ ] **Postman:** collection, environment, pre-request script, test script
- [ ] **REST Assured (Java):** kết hợp JUnit
- [ ] **Kỹ thuật:** JSON Schema validation, auth (JWT), negative test
- [ ] **Contract testing với Pact:** đọc hiểu là đủ

## 3b. UI Automation (3 tuần)

- [ ] **Selenium + Java + TestNG + Maven:** đúng như chương 2 giáo trình *Full Stack Testing* (locator strategy, explicit wait, chụp screenshot khi fail)
- [ ] **Kiến trúc & vận hành:** Page Object Model (POM), data-driven test, chạy parallel
- [ ] **Playwright (Java hoặc TypeScript):** hiện đại hơn, ít flaky hơn, đang được tuyển nhiều *(học thêm sau Selenium)*
- [ ] **BDD với Cucumber:** biết là đủ, chưa cần đào sâu

## Deliverable

- [ ] Một **framework automation hoàn chỉnh (API + UI)** với báo cáo **Allure**, đưa lên GitHub.
