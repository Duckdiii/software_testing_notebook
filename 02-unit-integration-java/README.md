# Giai đoạn 2: Unit & Integration Test với Java (Tuần 5–6 · 4 tuần)

> **Bám syllabus:** Tuần 5–6  
> **Trọng tâm:** Tận dụng lợi thế lập trình Java để vượt trội so với tester thông thường.

## Checklist kiến thức & kỹ năng

- [ ] **JUnit 5:** parameterized test, lifecycle, nested test *(cú pháp tương tự TestNG trong giáo trình)*
- [ ] **Mockito & AssertJ:** mock / stub / spy / verify và assertion fluent với AssertJ
- [ ] **Spring Boot Test:** `@WebMvcTest`, `@DataJpaTest`, `@SpringBootTest`, `MockMvc`
- [ ] **Testcontainers:** test với DB thật trong Docker *(rất hay được hỏi ở môi trường Java)*
- [ ] **JaCoCo:** đo coverage, hiểu rằng coverage cao chưa chắc test tốt
- [ ] **TDD:** thực hành `red → green → refactor`
- [ ] **Test pyramid:** đọc kỹ chương 14 *Agile Testing* và phần *"Automated Functional Testing Strategy"* trong *Full Stack Testing*

## Deliverable

- [ ] Đưa một module backend của **TechStore** lên **80% branch coverage**, kèm test có ý nghĩa chứ không phải test để lấy số.
